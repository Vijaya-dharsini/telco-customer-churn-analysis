# Telco Customer Churn Analysis

## 1. Project Overview

This project focuses on analyzing customer churn in the telecommunications industry using SQL, Python, and Power BI.

The main objective is to explore customer data, understand churn patterns, and identify insights that can help businesses improve customer retention.

## 2. Business Problem

Customer churn occurs when customers stop using a company's services.

For telecommunications companies, customer churn can affect revenue and business growth.

This project explores customer data to understand customer behavior and identify patterns associated with customers leaving the company.

## 3. Project Objectives

- Explore and understand the customer dataset.
- Perform data quality checks.
- Analyze customer characteristics and service usage.
- Explore patterns related to customer churn.
- Compare customer groups based on churn.
- Build an interactive Power BI dashboard.
- Present insights that can support business decisions.

## 6. SQL Analysis

Google BigQuery was used to explore and analyze the customer churn dataset.

A total of 18 SQL queries were prepared.

The analysis included:

- Understanding the dataset structure.
- Checking NULL, blank, and space values.
- Analyzing customer characteristics.
- Exploring customer tenure and monthly charges.
- Comparing customer groups based on churn.

**SQL File:** `SQL/telco_churn_analysis.sql`

## 7. Python Analysis

Python was used for further exploration and analysis of customer churn data.

The analysis was performed using Jupyter Notebook.

**Python File:** `Python/telco_churn_analysis.ipynb`

## 8. Power BI Dashboard

An interactive dashboard was developed using Power BI to present the customer churn analysis visually.

The dashboard helps users explore customer churn patterns and important business metrics.

**Dashboard Files:**
